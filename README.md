# Panchayat App

A lightweight front-end starter app for tracking panchayat projects, budgets, and priorities.

## Run locally

Because this is a static app, you can run it with any local file server.

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Features

- Dashboard cards for projects, budget utilization, and open issues
- Searchable table of village works
- Add/update status and progress for each work item in browser memory
